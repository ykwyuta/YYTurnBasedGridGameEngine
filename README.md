# 鉄盤戦線（TETSUBAN SENSEN）

9×9 の盤で交互に指す、サイバーパンクな世界観のターン制戦略ボードゲームです。
ネオンに光る都市の盤上で、近代兵器のユニット（歩兵・戦車・自走砲・ドローン・ミサイル）を操り、**工場を奪って生産力を伸ばし、敵の首都を歩兵で占領**すれば勝ちです。

ブラウザだけで動く静的サイトで、ビルドもサーバーも不要です。`index.html` をブラウザで開けばそのまま遊べます（GitHub Pages などにそのまま置いても動きます）。

- CPU 対戦（先手／後手、強さ 3 段階）
- 二人対戦（同じ画面で交互に）
- CPU 同士の観戦

## 企画書

### コンセプト

「将棋の“一手の重さ”と、ストラテジーゲームの“生産と経済”を一枚の盤に」。

将棋との一番の違いは**取った駒を使えない**こと。撃破された駒は盤から消えるだけで、戦力は自軍の拠点で**生産**して補充します。資金源である**工場**の奪い合いが中盤の焦点になり、終盤は首都の攻防になります。

| 将棋 | 鉄盤戦線 |
| --- | --- |
| 玉を詰ませたら勝ち | 敵の首都に歩兵が入ったら勝ち |
| 取った駒を打てる | 取った駒は消える。資金で生産する |
| 1手で1枚動かす | 1ターンに違う駒を2回行動 + 拠点ごとに1体生産 |
| 駒の強さは固定 | 駒には耐久値があり、拠点で補給・回復する |

ルールの骨格は将棋に着想を得ていますが、見た目はまったく別物です。夜のメガシティを舞台に、ネオンの格子で描いた盤、六角形のホログラム風トークン（線画アイコン）、ビル群の障害物、走査線エフェクトを使ったサイバーパンク調のデザインにしています。
### 陣営

| | 陣営 | 色・手番 | 設定 |
| --- | --- | --- | --- |
| 0 | **アークライト社**（ARCLIGHT CORP.） | シアン・先手 | 都市を支配する巨大企業。警備部隊と自律兵器で秩序を敷く。 |
| 1 | **緋蛇会**（HIDAKAI SYNDICATE） | マゼンタ・後手 | 地下ネットと闇市場を牛耳るサイバー極道。改造兵器で企業支配に抗う。 |

陣営名・説明は `js/rules.js` の `FACTIONS` だけで定義しているので、そこを書き換えれば画面全体に反映されます。

### 勝利条件

- 自軍の**歩兵**を敵の**首都**マスに移動させる（占領）と勝ち。
- 80 ラウンドで決着しなければ判定（資金＋収入×5＋残存戦力の合計）。
- 投了もできます。

### 1ターンの流れ

1. **収入**：首都 +2、所有している工場 1 つにつき +2。自軍の建物の上にいる駒は耐久が 1 回復。
2. **行動（2回）**：違う駒を 2 体まで動かせる。
   - 歩兵・戦車・ドローンは「移動 → 攻撃」までが 1 回の行動。
   - 自走砲・ミサイルは移動か攻撃のどちらか一方。
3. **生産**：自軍の首都・工場は**それぞれ 1 ターンに 1 体**生産できる。置けるのは建物のマスかその周囲 8 マス。生産した駒はそのターンは動けない。
4. ターン終了。

工場を増やすと**収入**と**同時に生産できる数**の両方が増えます。これが「工場を占領すると生産量が増える」という仕組みです。

### 建物・地形

| 名前 | 効果 |
| --- | --- |
| 首都（HQ） | 各軍に 1 つ。収入 +2・生産拠点。歩兵に占領されると負け。 |
| 工場（FAB） | 歩兵が入ると占領。収入 +2・生産拠点が 1 つ増える。奪い返せる。 |
| 包囲 | 建物の周囲 8 マスに敵の駒がいる間、その建物では生産できない。 |
| 塹壕 | 歩兵が自マスに掘る（1 行動）。中の地上駒は歩兵・戦車・自走砲から受けるダメージが 1 減る。戦車は進入不可。ミサイルの直撃で破壊される。 |
| ビル群 | 地上の駒は進入不可。ドローンは飛び越えられ、砲撃はビル越しに届く。 |

### 駒

| 駒 | コスト | 耐久 | 移動 | 攻撃 | 役割 |
| --- | --- | --- | --- | --- | --- |
| 歩兵 | 2 | 1 | 縦横 1 | 周囲 8 マスに 1 | 占領できる唯一の駒。塹壕を掘る。ドローンを撃てる。 |
| ドローン | 3 | 1 | 距離 3 以内へ飛行 | 周囲 8 マス。車両に 2、他に 1 | 塹壕無視。戦車・自走砲からは撃たれない。歩兵に弱い。 |
| 自走砲 | 5 | 2 | 8 方向に 1 | ちょうど距離 2 に 2 | 間接射撃（遮蔽を無視）。隣接・ドローンは撃てない。 |
| 戦車 | 6 | 3 | 縦横に最大 2 直進 | 周囲 8 マスに 2 | 高耐久の主力。塹壕に入れない。ドローンを撃てない。 |
| ミサイル | 7 | 1 | 縦横 1 | 距離 4 以内の任意マス | 使い捨て。着弾 3（塹壕無視・破壊）＋縦横隣接に 1。味方も巻き込む。 |

※ 距離はチェビシェフ距離（縦・横・斜めのどれでも 1 歩 = 1）です。

### 相性（じゃんけん構造）

- **歩兵の壁と塹壕**は戦車の突進を止める。
- **ドローン**は戦車・自走砲・塹壕の歩兵に強いが、**歩兵**に撃ち落とされる。
- **自走砲**は壁の後ろから歩兵を削る。懐に入られると弱い。
- **ミサイル**は固まった陣形や首都前の防衛線をまとめて崩す切り札。

9×9。点対称の配置で、アークライト社が下（先手）、緋蛇会が上（後手）。

## 操作方法

- 自分の駒をクリック → **緑に光るマス**：移動先、**赤い照準**：攻撃できる相手。
- 移動後に攻撃できる相手がいれば照準が出ます。攻撃しないなら「攻撃せず待機」。
- 生産パネルで駒を選ぶ → **光っているマス**をクリックで配置。
- ミサイルは「ミサイル発射」→ オレンジの範囲から着弾地点を選択（カーソルを合わせると巻き込み範囲を表示）。
- 敵の駒をクリックすると、その駒の移動範囲と攻撃が届く範囲を確認できます。
- Esc で選択解除。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要で、静的ファイルへのリクエストは無料プランでも無料・無制限です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. このブランチを `main` にマージしておく（公開したいブランチを本番ブランチにする）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログイン（無料アカウントで OK）→ **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYTurnBasedGridGameEngine` を選ぶ。
4. 設定はそのままで構いません。
   - ビルドコマンド：空欄
   - デプロイコマンド：`npx wrangler deploy`（既定値）
   - ルートディレクトリ：`/`
5. **デプロイ** を押すと `https://tetsuban-sensen.<あなたのサブドメイン>.workers.dev` で公開されます。

以降は本番ブランチに push するたびに自動で再デプロイされます。独自ドメインを使う場合は、Worker の **設定 → ドメインとルート** から追加します。

### 方法 B：手元のパソコンからコマンドで公開

Node.js が入っていれば、リポジトリのルートで次を実行します。

```sh
npx wrangler login    # 初回のみ。ブラウザで Cloudflare にログイン
npx wrangler deploy   # 公開（URL が表示される）
```

公開前に手元で確認したいときは `npx wrangler dev` で http://localhost:8787 に立ち上がります。

### 公開に関係するファイル

| ファイル | 役割 |
| --- | --- |
| `wrangler.jsonc` | Worker 名（`tetsuban-sensen`）と、リポジトリのルートを静的サイトとして配信する設定。URL の名前を変えたいときは `name` を書き換える。 |
| `.assetsignore` | 公開しないファイル（README や設定ファイルなど）。 |
| `_headers` | キャッシュとセキュリティ関連の HTTP ヘッダー。 |

## ファイル構成

```
index.html      画面
css/style.css   見た目
js/rules.js     ルールエンジン（盤面データ・合法手・状態遷移）
js/ai.js        CPU 思考（評価関数 + 相手の応手まで読む浅い探索）
js/ui.js        描画と操作
```

ルールエンジンは DOM に依存しない純粋な関数として書かれているので、Node.js からも読み込めます（CPU 同士の自動対戦でバランス調整に使用）。

```js
require('./js/rules.js'); require('./js/ai.js');
let s = Engine.newGame();
for (const a of AI.plan(s, 'normal')) s = Engine.apply(s, a);
s = Engine.endTurn(s);
```
